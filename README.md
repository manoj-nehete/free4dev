# free4dev
Free4Dev gives vibe coders free subdomains across 10 curated domains via a retro web CLI. Powered by Hetzner Anycast DNS, GitHub OAuth, mandatory Telegram 2FA, and 1-click presets for Vercel and Netlify. Featuring an anti-phishing shield, public WHOIS relay, and zero URL routing changes. Ship your side projects with zero friction.
